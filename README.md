# 在庫管理システム

日本・中国の **倉庫** と **委託店舗** の在庫を一元管理する Web アプリです。
在庫の登録は、画面からの **直接入力** と、**Excel / CSV / PDF のアップロード** の2通りに対応しています。

## 主な機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 地域（日本/中国）× 種別（倉庫/委託店舗）の在庫合計、拠点別在庫、最近の入出庫 |
| 在庫一覧 | 地域・種別・拠点・品番/商品名で絞り込み、Excel 出力 |
| 直接入力 | 入庫 / 出庫 / 棚卸（数量の上書き） / 拠点間移動（例：倉庫 → 委託店舗） |
| ファイル取込 | Excel・CSV・PDF を読み込み → 確認画面 → 反映（2段階） |
| 履歴 | すべての入出庫を記録（入力元：直接入力 / Excel / CSV / PDF） |
| 商品・拠点 | マスタ管理。拠点ごとに地域と種別を設定 |

出庫で在庫がマイナスになる操作はエラーになります。

## ファイル取込のルール

- ファイル内の表から「品番」「数量」の列を自動で探します（ヘッダーは1行目でなくても可）。
- 認識する列名の例
  - 品番: `品番` `商品コード` `型番` `JAN` `SKU` `货号` `商品编码`
  - 商品名: `商品名` `品名` `名称` `Item` `商品名称`
  - 数量: `数量` `個数` `在庫数` `販売数` `Qty` `库存` `销售数量`
  - 拠点（任意）: `拠点` `倉庫` `店舗` `委託先` `仓库` `门店`
  - 単位・備考（任意）
- 「拠点」列が空の行には、アップロード時に選んだ拠点を使います。
- 未登録の品番は、商品名があれば反映時に自動で商品登録されます。
- 「合計」「小計」の行は無視します。
- PDF は表として埋め込まれたものを読み取ります。表が見つからない場合は「品番 商品名 数量」の並びのテキスト行から推定します（スキャン画像の PDF は非対応）。
- CSV の文字コードは UTF-8 / Shift_JIS / GB18030 を自動判別します。
- 取込画面からテンプレート Excel をダウンロードできます。

## 起動方法

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

ブラウザで http://localhost:8000 を開き、まず「拠点」と「商品」を登録してください。

データは `data/stock.db`（SQLite）に保存されます。環境変数で変更できます。

- `STOCK_DATA_DIR`: データ保存ディレクトリ
- `DATABASE_URL`: SQLAlchemy の接続 URL（例：PostgreSQL）

## テスト

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

## 構成

```
app/
  main.py        画面・ルーティング（FastAPI）
  models.py      テーブル定義（拠点・商品・在庫・入出庫履歴・取込バッチ）
  services.py    在庫の増減・移動・取込反映ロジック
  importers.py   Excel / CSV / PDF の読み取り
  templates/     画面（Jinja2）
  static/        CSS
tests/
```
