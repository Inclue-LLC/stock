# 在庫管理システム

日本・中国の **倉庫** と **委託店舗** の在庫を一元管理する Web アプリです。
商品は **JANコード** で管理し、各拠点の在庫は **Excel / CSV / PDF のアップロード** でいつでも更新できます。
委託店舗ごとに、納品（日付別）・販売・在庫・消化率・上代ベースの金額を一覧で確認できます。

## 主な機能

| 画面 | 内容 |
| --- | --- |
| 在庫一覧 | 「商品別」（日本/中国 × 倉庫/委託店舗の在庫を横並び）と「拠点別」の2つの表示。検索、Excel 出力 |
| 拠点 | 倉庫・委託店舗の一覧（在庫数・最終更新）。拠点名から店舗別の明細へ |
| 店舗別の明細 | 商品ごとに 上代・納品（日付別）・販売・調整・在庫・消化率・販売金額。ブランド別の小計、Excel 出力 |
| 在庫の更新 | Excel・CSV・PDF を読み込み → 確認画面 → 反映。「在庫数を上書き」「納品（加算）」「販売（減算）」と日付を指定 |
| 入出庫履歴 | すべての増減を日付付きで記録 |
| 商品マスタ | JANコード・ブランド・上代で登録。Excel / CSV での一括登録・更新に対応 |

在庫の更新方法:

- **在庫数を上書き**: 店舗や倉庫から届いた在庫数（残数）でそのまま置き換えます。差分は「調整」として記録されます。
  「ファイルにない商品の在庫を0にする」を選ぶと、拠点の全在庫リストとして扱います。
- **納品・入庫（加算）**: 納品書・出荷明細から。指定した日付が納品日として店舗別明細の列になります。
- **販売・出庫（減算）**: 委託店舗の販売報告から。

出庫で在庫がマイナスになる操作はエラーになります。

## JANコード

- 8桁（JAN短縮）/ 13桁（JAN標準）に対応し、チェックデジットを検証します。
- 全角数字・ハイフン・Excel の数値セルは自動で整えます。Excel で先頭の 0 が落ちた12桁も補正します。
- Excel で `4.90123E+12` のような指数表記になったものは読めません。JAN の列を「文字列」にして保存してください。
- 品番は任意の補助コードです。取込ファイルで、JAN の代わりに品番で既存商品を指定することもできます。

## 商品マスタの一括登録

商品マスタ画面の「テンプレート」から、入力用の Excel（商品マスタ.xlsx）をダウンロードできます。
必須列は「JANコード」「商品名」で、「ブランド」「上代（税込）」「品番」「単位」「備考」は任意です。
JAN の列は文字列形式になっていて、桁数・チェックデジット・重複を「JANチェック（自動）」列で確認できます。
同じ JAN の商品がすでにある場合は、空欄以外の項目を上書きします。

## ファイル取込のルール

- ファイル内の表から「JANコード（または品番）」「数量」の列を自動で探します（見出しは1行目でなくても可）。
- 認識する列名の例
  - JAN: `JAN` `JANコード` `バーコード` `EAN` `条码` `条形码`
  - 品番: `品番` `商品コード` `型番` `SKU` `货号` `商品编码`
  - 商品名: `商品名` `品名` `名称` `Item` `商品名称`
  - 数量: `数量` `在庫数` `残数` `納品数` `販売数` `販売点数` `Qty` `库存` `销售数量`
  - ブランド・上代（任意）: `ブランド` `上代（税込）` `売価` `定価` — 商品マスタが空欄なら補完します
  - 拠点（任意）: `拠点` `倉庫` `店舗` `委託先` `仓库` `门店`
  - 単位・備考（任意）
- 「拠点」列が空の行には、アップロード時に選んだ拠点を使います。
- 未登録の JAN は、商品名があれば反映時に自動で商品登録されます。
- 「合計」「小計」の行は無視します。
- PDF は表として埋め込まれたものを読み取ります。表が見つからない場合は「JAN 商品名 数量」の並びのテキスト行から推定します（スキャン画像の PDF は非対応）。
- CSV の文字コードは UTF-8 / Shift_JIS / GB18030 を自動判別します。
- 取込画面からテンプレート Excel をダウンロードできます。

## 起動方法

Python 3.10 以上が必要です（macOS 標準の 3.9 では動きません。https://www.python.org/downloads/ から入れてください）。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

ブラウザで http://localhost:8000 を開き、まず「拠点」と「商品」を登録してください。

データは `data/stock.db`（SQLite）に保存されます。環境変数で変更できます。

- `STOCK_DATA_DIR`: データ保存ディレクトリ
- `DATABASE_URL`: SQLAlchemy の接続 URL（例：PostgreSQL）

JANコード対応前のバージョンで作った `data/stock.db` は使えません。起動時にエラーが出たら、そのファイルを削除してください。

## テスト

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

## 構成

```
app/
  main.py        画面・ルーティング（FastAPI）
  models.py      テーブル定義（拠点・商品・在庫・入出庫履歴・取込バッチ）
  services.py    在庫の増減・移動・取込反映・商品マスタ取込
  jan.py         JANコードの正規化とチェックデジット検証
  importers.py   Excel / CSV / PDF の読み取り
  xlsx_templates.py  ダウンロード用 Excel テンプレート
  templates/     画面（Jinja2）
  static/        CSS
tests/
```
